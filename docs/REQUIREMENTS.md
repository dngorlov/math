# Требования к тренажёру «!¡ матан»

Формат: **ID — требование.** Приоритет по MoSCoW: **M** — обязательно, **S** — желательно, **C** — можно, если останется время. Статус: ✅ сделано в текущей версии, 🔜 в плане (`TELEGRAM_PLAN.md`), ⬜ не начато.

Критерий приёмки написан так, чтобы его можно было проверить руками за минуту.
