# Пошаговый запуск: сайт + Telegram Mini App + бот

Всё делается один раз, примерно за час с небольшим. Иди строго по порядку: каждый шаг опирается на предыдущий. После каждого шага есть проверка — не переходи дальше, пока она не прошла.

Что понадобится:
- аккаунт GitHub;
- аккаунт Cloudflare (бесплатный тариф подходит);
- Telegram;
- Node.js 18 или новее на компьютере (скачать: nodejs.org, версия LTS).

Обозначения в инструкции — подставляй свои значения:

| Обозначение | Пример | Откуда |
|---|---|---|
| `<github>` | `ivanov` | твой логин на GitHub |
| `<repo>` | `matan` | имя репозитория |
| `<bot>` | `matan_trainer_bot` | username бота без @ |
| `<app>` | `app` | короткое имя Mini App |
| `<worker>` | `matan-api.ivanov.workers.dev` | адрес сервера после шага 4 |

## Шаг 1. Сайт на GitHub Pages

1. Создай репозиторий `<repo>` на GitHub (публичный).
2. Залей в него содержимое архива: все файлы должны лежать в корне репозитория, рядом с `index.html`.
3. Settings → Pages → Source: **Deploy from a branch**, Branch: `main`, папка `/ (root)` → Save.
4. Подожди 1–2 минуты.

**Проверка:** `https://<github>.github.io/<repo>/` открывает тренажёр, формулы отображаются.

## Шаг 2. Бот

В Telegram открой @BotFather:

1. `/newbot` → название (например, «!¡ матан») → username `<bot>` (должен заканчиваться на `bot`).
2. BotFather пришлёт **токен** вида `123456789:AA…`. Сохрани его в надёжном месте. Никому не показывай, не вставляй в код и не коммить в репозиторий.

**Проверка:** бот находится в поиске Telegram по `@<bot>`.

## Шаг 3. Mini App, домен и inline-режим

Всё там же, в @BotFather:

1. `/newapp` → выбери бота → название → описание → картинка 640×360 (подойдёт `icons/og.png` из архива, её можно обрезать) → GIF пропусти командой `/empty` → адрес: `https://<github>.github.io/<repo>/` → короткое имя `<app>` (например, `app`).
   Получишь ссылку `https://t.me/<bot>/<app>`.
2. `/setdomain` → выбери бота → `<github>.github.io` (без https и без пути). Это нужно для кнопки «Войти через Telegram» на сайте.
3. `/setinline` → выбери бота → текст-подсказка, например: `Топ-10 рейтинга`. Это включает вызов бота через `@<bot>` в любом чате.

**Проверка:** ссылка `https://t.me/<bot>/<app>` открывает тренажёр внутри Telegram.

## Шаг 4. Сервер на Cloudflare

Открой терминал (на Windows — PowerShell) в папке `worker` проекта.

```bash
# 4.1 Войти в Cloudflare (откроется браузер)
npx wrangler login

# 4.2 Создать базу. В ответе будет database_id — скопируй его
npx wrangler d1 create matan
```

Открой `worker/wrangler.toml` и заполни:
- `database_id` — из ответа команды 4.2;
- `ADMIN_IDS` — пока оставь пустым, заполнишь на шаге 8;
- `ALLOWED_ORIGINS` — `https://<github>.github.io`;
- `SITE_URL` — `https://<github>.github.io/<repo>/` (со слешем на конце);
- `BOT_USERNAME` — `<bot>`;
- `APP_NAME` — `<app>`.

```bash
# 4.3 Создать таблицы
npx wrangler d1 execute matan --remote --file=./schema.sql

# 4.4 Секреты. Каждая команда попросит ввести значение
npx wrangler secret put BOT_TOKEN        # токен из шага 2
npx wrangler secret put WEBHOOK_SECRET   # придумай длинную строку из букв и цифр, 30+ символов
npx wrangler secret put SESSION_SECRET   # ещё одна длинная строка, другая

# 4.5 Опубликовать
npx wrangler deploy
```

После `deploy` в терминале будет адрес `https://<worker>`. Заодно создадутся комнаты дуэлей (Durable Objects) и ежедневный запуск напоминаний в 22:00 МСК — отдельно ничего включать не нужно.

Длинную случайную строку для секретов можно получить командой:
`node -e "console.log(require('crypto').randomBytes(24).toString('hex'))"`

**Проверка:** `https://<worker>/api/top` в браузере показывает `{"top":[],...}`.

## Шаг 5. Подключить бота к серверу

Открой в браузере (вместо `<WEBHOOK_SECRET>` — строка из шага 4.4):

```
https://<worker>/admin/setup?key=<WEBHOOK_SECRET>
```

Сервер сам подключит вебхук, команды `/start` и `/top` и кнопку меню «Тренажёр».

**Проверка:** в ответе три раза `"ok":true`. Напиши боту `/start` — придёт сообщение с кнопкой «Открыть тренажёр».

## Шаг 6. Связать сайт с сервером и ботом

В репозитории открой `js/config.js` и заполни:

```js
API_BASE: 'https://<worker>',
BOT_USERNAME: '<bot>',
APP_NAME: '<app>',
GITHUB_REPO: '<github>/<repo>',
```

В `sw.js` увеличь `VERSION` (например, `'v2'` → `'v3'`). Закоммить и запушь.

**Проверка через 2 минуты:**
1. На сайте нажми значок профиля справа вверху → появилась кнопка «Log in with Telegram». Войди.
2. Открой тренажёр в боте → профиль показывает тебя, «Синхронизировано с сервером».
3. Реши 5 примеров в боте → обнови сайт → в шапке та же серия.
4. Сыграй в генератор → результат во вкладке «Рейтинг».
5. В любом чате напиши `@<bot>` → над клавиатурой карточка «Топ-10 рейтинга».

## Шаг 7. Проверить дуэль, совместный огонёк и напоминание

0. **Рейтинг.** Сыграй в генератор через бота: каждый ответ проверяет сервер, в рейтинг попадает только проверенный счёт.
1. **Дуэль.** На телефоне в боте: Генератор → «Дуэль 1 на 1» → «Создать дуэль» → «Пригласить соперника», отправь ссылку себе же на компьютер. На компьютере войди на сайте под **другим** аккаунтом Telegram (или попроси друга). Оба жмут «Я готов» → отсчёт 3-2-1 → 60 секунд.
2. **Совместный огонёк.** Нажми на знак серии → «Огонёк» → «Совместный» → впиши юзернейм друга → «Пригласить». Друг откроет тренажёр и увидит запрос; бот также напишет ему в личку. Когда ты решил задание дня, а партнёр ещё нет, в меню серии появится кнопка «Пнуть партнёра» (раз в 3 часа).
3. **Напоминание.** Открой в браузере `https://<worker>/admin/remind?key=<WEBHOOK_SECRET>&dry` — сервер покажет, кому и какой текст отправил бы сегодня, но ничего не отправит. Без `&dry` — отправит по-настоящему (так можно проверить, что сообщения доходят).

Важно про напоминания: бот может писать только тем, кто разрешил. Разрешение даётся при входе на сайте через Telegram, при `/start` в боте или при включении переключателя «Напоминание в 22:00» в профиле Mini App.

## Шаг 8. Админка

1. Открой тренажёр, нажми значок профиля — под именем написан твой **ID** (число).
2. В `worker/wrangler.toml` впиши его в `ADMIN_IDS`. Несколько преподавателей — через запятую: `ADMIN_IDS = "123456,789012"`.
3. В папке `worker`: `npx wrangler deploy`.
4. Теперь в профиле появится кнопка «Админка». В ней три вкладки:
   - **Статистика** — доля ошибок по темам и типам задач за 7 дней, 30 дней или всё время, отдельно по режимам; сверху пять типов задач для разбора на занятии.
   - **Пользователь** — найти участника по ID или @юзернейму и поправить серию, последний закрытый день, лучшую серию, число использованных заморозок и лучший счёт. Правка приходит на его устройства при следующем открытии и перезаписывает то, что там было.
   - **Рейтинг** — сбросить рейтинг (впиши слово СБРОС). Топ-100 перед сбросом сохраняется в архив сезонов на той же вкладке.

Статистика обезличена: сервер хранит только тему, тип задачи и количество ответов и ошибок за день. Учитываются ответы тех, кто вошёл через Telegram.

## Шаг 9. Для участников интенсива

Ссылки, которые можно давать в группе:

| Ссылка | Что открывает |
|---|---|
| `https://t.me/<bot>/<app>` | Тренажёр |
| `https://t.me/<bot>/<app>?startapp=endless` | Генератор задач |
| `https://t.me/<bot>/<app>?startapp=theory_rem` | Теорию по замечательным пределам |
| `https://t.me/<bot>/<app>?startapp=rating` | Рейтинг |
| `https://t.me/<bot>/<app>?startapp=duel` | Экран дуэлей |

Команды бота в чатах:

| Команда | Что делает |
|---|---|
| `/duel` | Бот создаёт комнату и присылает сообщение с кнопкой «Принять вызов» |
| `/duel @username` | То же, с обращением к конкретному сопернику |
| `/top` | Топ-10 рейтинга |
| `@<bot>` в любом чате | Карточки «Топ-10» и «Моё место» |

Чтобы команды работали в группе интенсива, добавь бота в группу. Если команды не появились в подсказках, ещё раз открой ссылку `/admin/setup` из шага 5.

Темы теории: `deriv`, `growth`, `lim`, `rem`, `circle`.

## Обновления в будущем

- **Сайт:** правишь файлы → увеличиваешь `VERSION` в `sw.js` → пушишь. Без смены версии у людей может остаться старая версия из кэша.
- **Сервер:** правишь файлы в `worker/src/` → `npx wrangler deploy` в папке `worker`.
- **Генераторы задач** (`js/gen/`): увеличь `GEN_VERSION` в `js/gen/index.js`, запушь сайт **и** выполни `npx wrangler deploy` — сервер генерирует задачи дуэли тем же кодом. Пока версии не совпадут, дуэль попросит обновить страницу.
- **Новые таблицы:** если база уже работает, а в обновлении появился новый файл в `worker/migrations/`, выполни его: `npx wrangler d1 execute matan --remote --file=./migrations/<файл>.sql`. Для новой базы достаточно `schema.sql`.

## Если что-то не работает

| Симптом | Причина и решение |
|---|---|
| Нет кнопки входа на сайте | Не выполнен `/setdomain` или указан не тот домен. Нужно ровно `<github>.github.io` |
| «Подпись Telegram не сошлась» | Неверный `BOT_TOKEN`. Повтори `npx wrangler secret put BOT_TOKEN` |
| Рейтинг: «Не удалось загрузить» | В `ALLOWED_ORIGINS` нет адреса сайта, или `API_BASE` с опечаткой |
| Бот молчит на `/start` | Не открыта ссылка `/admin/setup` из шага 5, или в ней неверный ключ |
| `@<bot>` ничего не показывает | Не выполнен `/setinline`. Проверь также, что в рейтинге есть хоть один результат |
| Сайт показывает старую версию | Не увеличен `VERSION` в `sw.js`. Временно: обновить страницу с очисткой кэша |
| Ошибки сервера | `npx wrangler tail` в папке `worker` показывает логи в реальном времени |
| Дуэль: «Версия тренажёра устарела» | Сайт и сервер собраны с разным `GEN_VERSION`. Задеплой оба |
| Дуэль не подключается | В `API_BASE` адрес с `https://` — дуэль сама перейдёт на `wss://`. Проверь, что `wrangler deploy` прошёл без ошибок |
| Напоминания не приходят | Человек не разрешил боту писать. Пусть нажмёт `/start` в боте. Проверка: ссылка `/admin/remind?key=…&dry` |
| «Админка доступна только преподавателям» | Твоего ID нет в `ADMIN_IDS`, или после правки не сделан `wrangler deploy` |
| «Обнови страницу: результаты теперь проверяются на сервере» | У человека закэширована старая версия сайта. Обновление подтянется само; можно перезапустить Mini App |
| Забег не попал в рейтинг | Слишком много ответов быстрее 0,6 секунды подряд — так отвечает только бот |

Отладка внутри Telegram: в Telegram Desktop включи Settings → Advanced → Experimental settings → Enable webview inspecting. Тогда в Mini App работает правый клик → «Inspect».
