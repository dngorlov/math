# !¡ матан — тренажёр по матанализу

Сайт и Telegram Mini App для подготовки (рейтинг защищён от накрутки, есть админка): теория, практика по темам, бесконечный генератор задач, дуэли 1 на 1, интерактивные графики, серия дней с заморозками, совместный огонёк, напоминания, общий рейтинг, бот с топ-10 и статистика ошибок для преподавателя.

**Запуск с нуля — [`docs/SETUP_GUIDE.md`](docs/SETUP_GUIDE.md).** Как всё устроено — [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

Чистый HTML, CSS и JavaScript-модули без сборки: GitHub Pages отдаёт файлы как есть.

## Запуск на компьютере

Модули не работают при открытии файла двойным щелчком — нужен локальный сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Публикация на GitHub Pages

1. Залей папку в репозиторий.
2. Settings → Pages → Deploy from branch → `main`, папка `/ (root)`.
3. Через 1–2 минуты сайт доступен по адресу `https://<имя>.github.io/<репозиторий>/`.

После изменения файлов увеличь `VERSION` в `sw.js` (`v1` → `v2`), иначе у пользователей может остаться старая версия из кэша.

## Настройки

Всё в `js/config.js`:

- `API_BASE` — адрес сервера (см. `worker/README.md`). Пока пусто, рейтинг и синхронизация с сайтом выключены.
- `BOT_USERNAME`, `APP_NAME` — бот и Mini App: для входа на сайте и ссылок «Поделиться».
- `GITHUB_REPO` — `имя/репозиторий` для кнопки «Сообщить об ошибке».
- `STREAK_GOAL` — сколько верных ответов в день нужно для серии.
- `FREEZES_PER_MONTH` — сколько заморозок в месяц.

## Как добавить вопрос в практику

Допиши в `data/bank.txt` в нужную тему:

```
Q: $\lim_{x\to0}\frac{\sin 7x}{x}$
A: $7$
W: $1$ ;; $\frac{1}{7}$ ;; $0$
E: $\sin 7x\sim 7x$.
```

## Как добавить генератор задач

В `js/gen/oral.js` (устные) или `js/gen/written.js` (письменные) добавь объект с `id`, `topic` и функцией `make(level)` и впиши его в массив `ORAL` или `WRITTEN` внизу файла. Устный возвращает `{ topic, kind, q, a, opts, e }`, письменный — `{ topic, kind, q, a, value, e }`, где `value` — числовой ответ, а `kind` — тип задачи для статистики (название добавь в `js/gen/kinds.js`).

Случайность — только через `R` и `shuffle` из `js/gen/util.js`, не через `Math.random`: иначе у игроков дуэли задачи разойдутся. После любых изменений генераторов увеличь `GEN_VERSION` в `js/gen/index.js` и задеплой сервер.

## Проверка перед пушем

```bash
npm install
npm run check
```

Скрипт рендерит каждую формулу банка и по 240 задач каждого генератора, проверяет варианты ответа и разборщик ответов. То же самое делает GitHub Actions при каждом пуше.

## Режим отладки серии

Открой сайт с `?debug=1` в адресе и нажми на знак серии: внизу меню появятся кнопки «Решить день», «Следующий день», «Пропустить день», «Пропустить 2 дня», «Вернуть заморозки», «Серия 29» и т. д. Так можно посмотреть все анимации, не дожидаясь 100 дней. Сдвиг времени хранится в браузере; кнопка «Сброс» возвращает серию к нулю.
